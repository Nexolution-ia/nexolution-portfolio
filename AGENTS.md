# Orientações do projeto

- Use a skill Impeccable para analisar e modificar o front-end deste site, conforme preferência explícita do usuário.
- O objetivo do redesign é apresentar a Nexolution como uma empresa de software com uma presença visual distinta e chamativa.
- Use prints e gravações reais dos projetos fornecidos pelo usuário ou capturados dos projetos que ele indicar. Não apresente interfaces inventadas como trabalhos entregues.
- Confirme com o usuário os resultados e números dos cases existentes antes de usá-los como evidência no novo posicionamento.
